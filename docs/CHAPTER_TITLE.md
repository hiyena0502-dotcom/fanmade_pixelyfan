# 챕터 타이틀 구현

플레이 화면 1920×1080 좌표에서 SVG 원호·동심원·방사선·좌우 메달·곡선·끊어진 이중선·마름모·별 장식을 표시한다. 배경 장면은 그대로 유지하고 중앙의 타원형 음영만 가장자리로 갈수록 투명해진다. 불투명 패널이나 전체 화면 암막은 사용하지 않는다.

새 게임은 기존 독백 → `PROLOGUE 0 / 초대` → 기존 opening 이벤트 순서로 진행된다. 기존 독백과 이벤트의 상대 순서, 대사, 이미지, 게시 콘텐츠는 변경하지 않는다. 독백 미리보기에는 타이틀을 삽입하지 않는다. 이전 저장 파일은 기록된 단계 그대로 복원하며 강제로 새 타이틀을 삽입하지 않는다.

| 구간 | 시간 |
| --- | --- |
| 중앙 금빛 점, 장면 준비 | 0–0.26초 |
| 원형 문양·장식선 전개 | 0.15–1.14초 |
| 영문 표기 등장 | 0.90–1.16초 |
| 첫 북소리·큰 제목 등장 시작 | 1.12초 |
| 두 번째 북소리·제목 완성 | 1.44초 |
| 읽기 유지, 미세한 빛의 이동 | 1.44–4.03초 |
| 자연스러운 퇴장·게임 복귀 | 4.03–4.80초 |

각 장식 그룹과 텍스트는 독립적인 Web Animations를 사용하되 게임의 저장 가능한 elapsed 값으로 함께 이동한다. 게임 일시 정지 중에는 연출 시간이 흐르지 않는다. 모션 끄기 또는 OS 동작 줄이기에서는 회전·확대·빛 이동 없이 페이드만 유지한다. Escape·Enter·Space로 타이틀을 건너뛰거나 메뉴를 열 수 없으며 타이틀 종료 후 UI가 돌아온다.

한글은 기존 `assets/fonts/gowun-wardrobe-bold.woff`의 Gowun Batang Bold를 사용한다. 동봉된 `Gowun-Batang-OFL.txt`는 SIL Open Font License 1.1이며 상업적·비상업적 사용 및 소프트웨어 번들링을 허용한다. 기존 라이선스 파일을 유지했다. 영문은 이용자 기기의 Georgia/Times New Roman 계열 시스템 서체를 사용하고 폰트 파일을 추가 배포하지 않는다.

효과음은 외부 샘플 없이 sounds.js에서 직접 생성한 두 개의 따뜻한 저음 북소리이다. 두 번째 타격에는 1.85초의 부드러운 저음 잔향을 포함한다. 기존 효과음 켜기·효과음 음량·전체 음량 설정을 사용한다.

이후 이벤트에서 `{type:'chapter-title',number:1,title:'제목'}`을 지정하면 `CHAPTER I`로 재사용된다. 번호 2·3은 `CHAPTER II`·`CHAPTER III`가 된다. 새 개발자 편집 UI는 추가하지 않았다. 연출 중 저장된 기록은 elapsed 시점으로 복원되며 이미 지난 북소리를 다시 재생하지 않는다.
