# 개발자 모드 · 간편 편집

## 들어가기

기존 사이트의 **설정 → 개발자 모드**에서 제작자 코드로 로그인한다. 로그인 후 편집 메뉴에서 챕터·콜렉션·플레이를 고른다. 주소와 인증은 기존 사이트 안에서 유지한다.

개발자 모드에서만 화면 위에 **편집 메뉴 / 일반 화면**이 보인다. ‘일반 화면’은 개발자 모드를 끄고 공개 콘텐츠를 다시 읽는다. 로그인 인증과 서버 변경 권한은 기존 방식을 유지한다.

## 저장과 반영

- **저장**: 이미지를 포함한 편집을 서버 임시 저장본에 보관한다. 일반 플레이 화면에는 아직 공개하지 않는다.
- **미리보기**: 수정 내용을 확인한다. 책 편집 창은 현재 입력도 미리보기에 적용한다. 플레이는 일반 슬롯에 기록하지 않는 테스트 화면으로 열린다.
- **사이트에 반영**: 저장이 필요한 편집을 먼저 저장한 뒤 공개한다. 다른 제작 창과 충돌하면 기존 서버 revision 검사로 덮어쓰기를 막는다.

책 편집도 ‘편집 적용 → 별도 임시 저장’을 거치지 않고 편집 창에서 직접 저장할 수 있다. 미리보기 등록/클리어 상태는 실제 플레이 진행을 바꾸지 않는다.

## 플레이 편집

상단 탭으로 장소·캐릭터·아이템·퍼즐·대화/이벤트를 전환한다. 항목 추가 시 내부 ID는 자동 생성한다.

- **장소**: 배경 이미지, 조사 대상, 등장인물, 이동 연결을 각각 펼쳐 수정한다. 대화·장소·아이템은 등록된 이름에서 선택한다.
- **대화·이벤트**: 순서 카드에서 대사, 선택지와 후속 내용, 아이템 획득, 콜렉션 등록, 이동, 연출 등을 입력한다. 단계 이동·복제·빼기와 되돌리기를 제공한다.
- **진행 조건**: 진행 표시·아이템·퍼즐·방문 조건을 선택한다. 새로운 진행 표시도 내부 ID를 자동 생성하고 한글 이름으로 관리한다.
- **이미지**: 업로드·교체·삭제, 크기·위치·회전 슬라이더, 미리보기 이미지 드래그, 위치 초기화. 책·UI 전체에는 적용하지 않는다.
- **화면에서 위치 조절**: 테스트 화면의 조사 영역과 등장인물을 드래그한 뒤 ‘조절 완료’로 편집 창에 돌아온다. 편집 중 플레이 조사는 멈춘다.

고급 데이터 직접 편집과 시작·자동 저장 설정은 접힌 영역에 보관한다. 일반 폼으로 변경하지 않은 조건별 분기 등의 기존 데이터는 유지한다.

## 보관 한계

미저장 플레이 편집은 현재 브라우저의 임시 보관을 사용한다. 다른 기기까지 보관하려면 ‘저장’을 누른다. 서버 저장과 공개는 구분하며, 일반 플레이 저장 슬롯은 계속 기기·브라우저별 기록이다.

## 확인

기존 자동 테스트 43개 통과. 격리된 개발자 브라우저 검사에서 플레이 편집 28개, 챕터 편집 8개·콜렉션 편집 8개를 통과했다. UI 검사는 인증·서버 응답을 테스트 데이터로 격리해 실제 공개 콘텐츠를 바꾸지 않았다. 서버 API와 인증 방식은 변경하지 않았다.

### 프롤로그 시작 독백

플레이 편집 → **프롤로그 독백**에서 장면을 추가하고 직접 대사를 적습니다. 대사는 초기 상태에서 비어 있습니다. 새 게임은 독백 장면들을 보여 준 다음 기존 시작 이벤트로 이어집니다. 빈 장면도 `시작` 버튼으로 진행할 수 있습니다. 저장 기록은 현재 독백 장면과 글자 출력 위치를 유지합니다.

- **이미지 계속 추가**: 여러 파일을 한 번에 선택하거나 반복해서 올립니다. 각 장면당 최대 100개, 파일당 20MB입니다.
- 목록 아래 레이어가 앞에 보입니다. `뒤로`·`앞으로`, 표시 여부, 불투명도, 복제·제거를 지원합니다.
- 선택한 레이어의 크기·가로/세로 위치·회전을 조절합니다. 기본은 원본 전체가 보이는 방식이며 화면 채우기를 별도로 선택할 수 있습니다.
- 움직임 없음 / 떠오르기 / 흔들기 / 크기 변화 / 좌우 이동 / 나타나기 중 선택하고 강도·시간·시작 지연을 조절합니다. 일반 설정의 모션 끄기와 메뉴 일시정지를 따릅니다.
- **이 독백 미리보기**는 현재 장면에서 시작합니다. **저장**은 개발자 초안만 저장하고 **사이트에 반영**은 일반 플레이에 공개합니다. 테스트는 플레이 저장 슬롯을 변경하지 않습니다.
- 배경색, 대사 위치·너비, 장면 순서는 접힌 설정에서 바꿀 수 있습니다. 책이나 메인 화면 배치는 변경하지 않습니다.
