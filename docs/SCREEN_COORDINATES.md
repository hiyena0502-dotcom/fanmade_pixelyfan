# 화면 좌표 기준

메인·메뉴(저장 슬롯, 책, 옷장, 설정)는 3000×1440(25:12), 실제 플레이는 1920×1080(16:9)입니다. stage.js의 fit / gameFit이 브라우저 내부 크기로 동일한 비율의 배율과 중앙 여백을 계산합니다. enterPlay가 setPlaying(true)를 호출하기 전까지 슬롯 화면은 메뉴 좌표계를 유지합니다.

메뉴 여백은 기존 갈색 #4A3529, 게임 여백은 #303A32입니다. 프롤로그 최초 독백은 기존 확정 연출대로 전체 브라우저가 단색 #534439이므로 이 구간의 여백도 같은 갈색입니다. 독백의 논리적 스테이지는 계속 1920×1080입니다.

게임의 캐릭터, 조사 좌표, 이미지 레이어는 기존 정규화된 백분율 좌표를 그대로 사용합니다. 배경·캐릭터·핫스폿·대화창은 같은 스테이지의 단일 CSS 변환 안에서 확대됩니다. 저장 데이터와 원본 이미지의 픽셀을 변경하거나 마이그레이션하지 않습니다.

## 원본 비율이 다른 기존 이미지

집 앞의 sky/clouds/garden/house/stones/bush.webp(assets/title/layers-oct8)는 각각 2048×983(약 25:12)입니다. 플레이에서 기존 cover 대신 contain으로 전체 원본 비율을 유지합니다. 기존 집·돌·덤불의 20% 이동과 조사 좌표는 보존합니다. 16:9 원본 배경은 추후 제작자가 제공할 때 교체합니다. 새 옷장 배경(wood-room-user-oct11.webp)은 제공된 1916×821 PNG를 동일한 픽셀의 무손실 WebP로 저장했고 contain으로 표시합니다. 메인 장식 레이어나 카드·옷장 파츠에는 변경을 적용하지 않습니다.

개발자 미리보기의 게임 배율은 1920 기준으로 표시합니다. 개발자 기능, 업로드 자료, 스토리, 발행 콘텐츠와 브라우저 저장 DB는 그대로 보존합니다.
