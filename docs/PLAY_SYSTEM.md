# 플레이 기초 시스템 · rebuild-v2

기존 메인 화면과 옷장 디자인을 유지하면서 같은 사이트에 제작자 편집 모드와 포인트 앤 클릭 플레이 기초 시스템을 추가했다. 정식 스토리와 새 일러스트는 제작하지 않았다. 프롤로그와 현관의 임시 문장은 `[테스트]`로 표시한다.

## 구현 내용

- 새 게임·이어하기·게임 내부 저장/불러오기에서 공통으로 사용하는 5개 슬롯. 수동 기록과 자동 기록은 별도 저장하며 새 게임/수동 덮어쓰기는 확인을 요구한다.
- 장소, 이벤트 단계, 글자 출력 위치, 선택지, 플래그, 캐릭터 배치, 퍼즐, 조사 횟수, 가방, 도감, 의상 이미지와 플레이 시간을 저장하고 복원한다.
- 16:9 비율을 유지하는 플레이 화면, 양피지 대화창, 조건부 캐릭터·오브젝트·이동, 반복 조사, 아이템 사용과 소모, 선택지, 숫자 퍼즐, 자동 진행·읽은 대사 스킵·지난 대사.
- 메뉴를 열면 출력과 이벤트 진행을 멈춘다. 도감으로 이동했다 돌아와도 원래 플레이 상태를 복원한다. 가방의 소모품과 도감의 발견 기록은 분리한다.
- 기존 집 앞 배경과 효과음 재사용. 새 캐릭터·아이템·현관 배경은 빈 영역으로 남겼다. 일반 탐색에서 꿈뜰이는 기본 숨김이다.
- 제작자 인증 뒤 동일 사이트에서 편집. 챕터/도감 정보·이미지 업로드, 교체, 삭제, 크기, 위치, 회전, 이미지 드래그, 되돌리기/다시 실행.
- 장소·캐릭터·표정·배경·아이템·퍼즐·대화/이벤트 편집. 장소별 캐릭터 배치와 클릭 영역 조정, 테스트 장면 이동, 이벤트 테스트, 영역 표시·드래그. 수정은 이미지/데이터에만 적용한다.
- 공통 콘텐츠는 서버의 임시 저장본과 공개본을 분리한다. 충돌 감지로 다른 편집 내용을 덮어쓰지 않는다. 이미지와 공개 기록은 사이트 반영 후 다른 브라우저에도 전달된다. 플레이 진행/개발자 미리보기 해금 상태는 공개하지 않는다.
- 책장 넘김과 색인 움직임, 플레이에서 획득한 도감 연결. 미등록 이름/설명은 숨기고 일반 화면의 이미지 업로드 안내는 제거했다.

## 제작자 사용 방법

1. 기존 메인 화면의 **설정 → 개발자 모드**에서 별도로 제공한 제작자 코드를 입력한다. `?edit=1`은 로그인 창을 여는 용도이며 인증을 우회하지 않는다.
2. 챕터·콜렉션의 **개발자 기록 편집**, 플레이의 **장면 편집**을 연다.
3. **편집 적용**은 브라우저 편집본, **임시 저장**은 서버의 비공개 편집본, **사이트에 반영**은 일반 플레이어에게 공개하는 작업이다. 서버 반영 전 임시 저장을 먼저 한다.
4. 게임 편집에서 **테스트 시작** 후 **이 장면 테스트**나 **이 이벤트 테스트**를 사용한다. 개발자 테스트는 실제 플레이 저장 슬롯을 쓰지 않는다.
5. 이전 브라우저에 있던 책 편집 정보는 **브라우저 기록 가져오기**로 명시적으로 가져올 수 있다. 기존 옷장 저장소는 그대로 유지했다.

## 저장 범위와 남은 작업

- 플레이 슬롯·의상 복사·페이지 상태는 해당 기기/브라우저의 IndexedDB에 저장한다. 기기 간 게임 진행 동기화, 로그인별 클라우드 세이브, 저장 내보내기/가져오기는 아직 제공하지 않는다. 브라우저 데이터를 지우면 로컬 기록이 사라질 수 있다.
- 제작자 이미지와 공통 게임/책 콘텐츠는 Vercel의 비공개 Blob 저장소에 보관한다. 공개된 기록에서 참조하는 이미지만 일반 사용자에게 제공한다. 삭제 버튼은 참조에서 제거하며 원본 파일의 영구 삭제 기능은 제공하지 않는다.
- 정식 시나리오, 여러 세계/챕터, 실제 퍼즐 콘텐츠, 정식 인물/아이템 그림, 완성된 프롤로그 연출은 추가 제작이 필요하다. 현재 집 앞→현관은 시스템 테스트 흐름이다.
- 오브젝트 연결·조건·선택지·컷신 순서는 구조화된 JSON 입력이다. 시각적인 노드 편집기, 대사 행 단위 편집기, 자동 참조 연결 도구는 아직 없다.
- 캐릭터 이동/표정/확대·축소 데이터와 이미지 표시·암전·대기·흔들림을 지원한다. 캐릭터 경로를 따라 움직이는 전용 애니메이션 타임라인은 아직 없다.
- 종이 넘김 소리를 교체할 수 있는 기존 연결을 유지했다. 메뉴 버튼에는 새 효과음을 추가하지 않았다.

## 검증

- Node 테스트 37개 통과: 기존 설정/효과음/옷장/책 검증 포함.
- 실제 서버 저장·공개·충돌·인증 분리 검증 7개 통과.
- 실제 SDK의 인증된 비공개 이미지 업로드 성공. 익명 편집 401, CSRF 없는 변경 403 확인.
- 브라우저 플레이 24개 검증 통과: 조사, 반복, 선택지, 이동, 아이템 소모와 기록 유지, 퍼즐, 자동 저장, 이어하기, 메뉴 일시 정지, 16:9.
- 브라우저 책 편집 11개 검증 통과: 업로드, 이미지 변형, 되돌리기/재실행, 책 크기 고정, 임시 저장/공개 분리, 플레이 진행 보존.
- 브라우저 게임 편집 10개 검증 통과: 배경 업로드 연결, 이미지 변형, 되돌리기/재실행, UI 고정, 공개/임시 저장 분리, 테스트 진행 저장 방지.
- 수동 저장 취소/확인과 플레이→도감→원래 장면 복귀를 직접 확인했다.

검증용 페이지와 테스트 API는 별도 QA 브랜치에만 두며 `rebuild-v2` 배포에는 포함하지 않는다.
