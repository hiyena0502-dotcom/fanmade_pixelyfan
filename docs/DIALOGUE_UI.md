# 대화·독백 편집과 간단한 자막

## 1. 같은 흐름에서 이어 쓰기
개발자 메뉴 → 프롤로그 독백에서 하나의 배경 장면에 독백, 멤버 대사, 리액션을 계속 추가한다. 이미지 레이어는 그대로 유지된다. 대화·이벤트 편집에서도 하나의 단계 목록에 계속 이어 쓴다. 화자, 표시 방식, 표정, 본문을 줄마다 지정하고 순서를 바꿀 수 있다. `화자 이름: 대사` 형식으로 여러 줄을 붙여 넣을 수도 있다. 이름 없는 다음 줄은 앞 대사에 이어진다.

한 줄은 최대 8000자, 한 흐름은 최대 300줄이다. 긴 본문은 글씨 크기를 유지하면서 현재 화면에 맞는 분량으로 나누어 출력한다. 첫 클릭은 현재 분량을 완성하고 다음 클릭은 다음 분량 또는 다음 줄로 이동한다. 새 장면은 배경 자체를 바꿀 때만 추가한다.

## 2. 기본 대화창
크림색 양피지, 짙은 갈색 본문, 가로·세로 중앙 정렬을 유지한다. 이름표는 왼쪽 위, 다음 표시는 오른쪽 아래에 둔다. AUTO, SKIP, LOG를 제공한다. 일반 대사에는 추가 말풍선이 없다. 중앙 독백 표시 방식을 고르면 기존 독백 화면에서 출력한다.

## 3. 멤버별 고유색
잠뜰은 파랑, 각별은 노랑, 공룡은 초록, 라더는 빨강, 수현은 보라, 덕개는 주황이다. 꿈뜰이는 별도 팔레트다. 사용자가 지정한 디자인 색상이며 공식 영상의 정확한 색상으로 표시하지 않는다. 캐릭터 편집의 고유 자막 색상에서 고유색·연한 보조색·자막 글자색을 한 번 바꾸면 해당 캐릭터 자막에 자동 적용된다. 본문은 공통 갈색이다.

## 4. 선택적인 추가 말풍선
기본 대사 아래 `자막 연출 설정`에서 추가 말풍선을 켠다. 한 대사당 하나만 지원한다. 일반 강조, 속마음, 놀람, 정적, 간단한 강조 자막 중에서 선택한다. 화자 고유색을 자동으로 사용하고 선택한 캐릭터 위치를 따른다. 자동 배치가 화면·대화창·캐릭터 얼굴과의 겹침을 줄인다. 직접 좌표는 우선 적용하되 화면과 대화창 안으로 잘리지 않도록 보정한다. 위치·크기는 게임 화면 기준이며 화면 크기가 달라도 비율을 유지한다.

## 5. 애니메이션과 소리
추가 자막은 없음, Fade, 작은 Pop만 지원한다. 화면 전체를 흔드는 자막 프리셋은 없다. 전역 모션 끄기를 따른다. 필요한 경우에만 접힌 고급 설정에서 표시 시간·등장 대기·앞뒤 순서·색상·여러 대사 동안 유지·효과음을 지정한다. MP3, OGG, WAV, M4A 효과음을 10MB 이하로 업로드할 수 있다. 소리가 없어도 자막은 정상 작동하며 전역 효과음·음량 설정을 따른다. 버튼에는 소리를 추가하지 않는다.

## 6. 진행과 입력
왼쪽 클릭, Space, Enter로 현재 글을 완성하거나 다음으로 진행한다. AUTO는 자막의 표시 시간을 고려한다. SKIP은 기존 읽은 대사 제한 설정을 따른다. 선택지에서 AUTO가 멈추고 선택 후 재개한다. 이전 대사의 자막은 자동 제거하며 유지 옵션도 표시 시간·장소 전환·이벤트 종료에 따라 정리된다. 메뉴와 편집 화면이 열린 동안 출력과 자막 타이밍을 멈춘다.

## 7. 저장과 호환성
대사 본문과 선택적 `caption` 연출 데이터를 분리한다. 고유색은 `characters[].subtitleStyle`에 저장한다. 독백 장면은 `monologue.pages[].lines` 순서대로 재생하며 기존 단일 `text` 데이터는 첫 번째 줄로 옮긴다. 레이어 설정은 유지된다. 캐릭터 그림이나 확정 스토리를 임의 생성하지 않는다.

편집 내용·이미지·효과음은 기존 인증된 임시 저장/사이트 반영 절차를 사용한다. 임시 저장은 공개본과 분리된다. 플레이 위치와 슬롯은 브라우저 IndexedDB에 저장하므로 다른 브라우저·기기로 자동 동기화되지 않는다. 개발자 미리보기는 플레이어 슬롯을 변경하지 않는다. 테스트 대사는 QA 전용 화면에만 두고 실제 공개 콘텐츠에 반영하지 않는다.

## 8. 확인 범위
멤버 색상 전환, 일반 대사에 자막이 없는 상태, 선택적인 자막, 캐릭터 이동 추적, 화면 경계, 클릭/키보드 진행, AUTO/SKIP/LOG, 화면 크기 변화, 연속 독백·멤버 대사, 저장 복원과 오디오 권한을 확인한다. 여러 명의 동시 말풍선이나 복잡한 끼어들기 연출은 이번 범위에 포함하지 않는다. 기존 이미지 레이어의 움직임 설정은 그대로 유지한다.
