# 시작 독백 및 확대 조사

시작 독백은 `prologue-opening` 이벤트의 독백 줄에만 적용됩니다. 단색 #534439, 글씨 #F5E8D4, 중앙 배치, 문장 전체 표시와 180ms 페이드만 사용합니다. 기존 대사·이미지 레이어 데이터는 삭제하지 않습니다. 다른 이벤트의 독백 및 일반 대사는 기존 렌더링을 사용합니다. 긴 독백은 같은 문장을 화면 높이에 맞춰 나눠 보여 줍니다. 클릭·Enter·Space로 진행하며 시작 독백 중 자동 진행과 메뉴는 숨깁니다.

## 추후 콘텐츠 연결

`game.inspections` 목록에 `{id, name, background, objects, layers?, actors?}`를 등록합니다. `background`는 별도의 업로드 asset ID입니다. 정식 상세 이미지나 조사 대상은 이번 변경에서 추가하지 않았습니다.

기존 장소 또는 상세 화면의 objects에 `{id, name, kind: 'closeup', to: '등록한-상세-ID', rect: {x,y,w,h}}`를 연결하면 진입합니다. 좌표는 게임 영역 기준 0~100%입니다. 상세 화면의 일반 objects는 기존 `event`, `use`, `condition`을 그대로 사용하므로 대사·아이템·퍼즐 이벤트를 연결할 수 있습니다. 이벤트 단계에서도 `{type:'closeup', to:ID}` 및 `{type:'closeup-back'}`를 사용할 수 있습니다. 새 개발자 편집 기능은 추가하지 않았습니다.

상세 화면은 기본 장소를 변경하지 않으며 inspectionStack에 최대 20단계까지 저장합니다. 뒤로가기는 한 단계씩 복귀하고 아이템·플래그·퍼즐 진행을 유지합니다. 부모 화면의 이벤트 이미지·명암도 복귀 시 복원합니다. 새 장소 이동은 조사 스택을 비웁니다. 삭제된 상세 화면을 포함한 저장은 유효한 이전 조사 화면까지만 복구하며 구버전 저장은 기본 장소에서 복구합니다. 저장 위치는 기존과 동일한 브라우저 IndexedDB이며 기기 간 자동 동기화하지 않습니다.

## 화면 변경 범위

챕터·콜렉션에서 스티커, 테이프, 꽃 완료 스탬프 등 장식을 숨겼습니다. 완료 상태 텍스트, 주요 콘텐츠 이미지, 업로드 데이터, 책과 메뉴 기능은 유지합니다. 저장 슬롯의 꽃 봉인 장식만 제거했습니다. 옷장은 CSS 레이아웃만 조정해 세로 거울 공간을 늘렸으며 캐릭터·파츠 좌표와 원본은 변경하지 않았습니다.
