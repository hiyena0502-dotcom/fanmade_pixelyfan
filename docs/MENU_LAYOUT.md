# 메뉴 화면 및 옷장 여백 조정 (2026-10-11)

마지막 요청에 따라 메뉴의 필러박스를 제거한다. 3000×1440은 제작 기준으로 유지하며 실제 메뉴 캔버스는 브라우저 비율에 맞춰 확장한다. 실제 게임만 1920×1080 및 기존 중앙 여백을 유지한다. 새 게임과 이어가기의 슬롯 선택도 메뉴 규칙을 사용한다.

## 구현

- `stage.js`: menuFit으로 캔버스 확장. 텍스트 가독성 배율과 이미지 좌표는 별도로 유지한다.
- `wardrobe.css`: 기존 나무 배경을 cover로 화면 전체에 표시해 배경 자체의 빈 띠도 제거한다.
- `stage.css`: 실제 게임의 장소 배경만 object-fit:cover. 원본 파일·저장 좌표·캐릭터 표시 규칙은 보존한다.
- `menu-layout.css`: 옷장 가로 84%, 세로 82% 이내, 책 82%/80% 이내. 최대 크기도 화면별로 제한한다. 메인 설정은 최대 760×650 논리 픽셀 및 높이 74% 이내다.
- 옷장 상단 간판과 줄은 외곽선 안으로 넣고 저장 슬롯에 144px 행 높이를 확보한다. 아이템 카드 행 높이는 max-content로 확보하고 목록만 스크롤한다. 1:1 썸네일과 48px 이름 표시 규칙은 유지한다.
- 설정의 헤더·닫기·탭·완료 버튼은 고정하고 내용만 필요한 경우 스크롤한다. 게임 내 설정과 도감 오버레이에는 새 메뉴 패널 크기를 적용하지 않는다.
- 메인 집·일기장의 기존 CSS 배치, 프롤로그 순서·타이틀, 장착 기능, 이미지·이벤트 데이터, 저장 시스템과 개발자 기능은 보존한다.

## 검증

브라우저 검증은 별도 QA 배포에서 3440×1440, 2520×1080, 1920×1080, 1920×900, 1600×1000 화면을 사용한다. 패널 경계, 글씨, 간판·줄, 5개 슬롯 및 클릭 영역, 썸네일, 착용·저장·불러오기, 책 카드·분류, 설정 탭·닫기를 확인한다. 검증용 이미지와 QA 페이지는 정식 브랜치에 포함하지 않는다.
