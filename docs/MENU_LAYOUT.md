# 메뉴 화면 및 옷장 여백 조정 (2026-10-11)

마지막 요청에 따라 메뉴의 필러박스를 제거한다. 3000×1440은 제작 기준으로 유지하며 실제 메뉴 캔버스는 브라우저 비율에 맞춰 확장한다. 실제 게임만 1920×1080 및 기존 중앙 여백을 유지한다. 새 게임과 이어가기의 슬롯 선택도 메뉴 규칙을 사용한다.

## 구현

- `stage.js`: menuFit으로 캔버스 확장. 텍스트 가독성 배율과 이미지 좌표는 별도로 유지한다.
- `wardrobe.css`: 기존 나무 배경을 cover로 화면 전체에 표시해 배경 자체의 빈 띠도 제거한다.
- `stage.css`: 실제 게임의 장소 배경만 object-fit:cover. 원본 파일·저장 좌표·캐릭터 표시 규칙은 보존한다.
- `menu-layout.css`: 옷장 가로 84%, 세로 82% 이내, 책 82%/80% 이내. 최대 크기도 화면별로 제한한다. 메인 설정은 최대 760×650 논리 픽셀 및 높이 74% 이내다.
- 옷장 상단 간판과 줄은 외곽선 안으로 넣고 거울이 왼쪽 전체 높이를 사용하도록 저장 슬롯을 오른쪽 목록 아래로 배치한다. 저장 슬롯에 168px 행 높이를 확보하고 버튼을 세로로 쌓아 작은 폭에서도 잘리지 않게 한다. 거울 폭은 사용 가능한 높이의 60% 이내로 제한해 세로 형태를 유지한다. 아이템 카드 행 높이는 max-content로 확보하고 목록만 스크롤한다. 1:1 썸네일과 48px 이름 표시 규칙은 유지한다.
- 설정의 헤더·닫기·탭·완료 버튼은 고정하고 내용만 필요한 경우 스크롤한다. 게임 내 설정과 도감 오버레이에는 새 메뉴 패널 크기를 적용하지 않는다.
- 메인 집·일기장의 기존 CSS 배치, 프롤로그 순서·타이틀, 장착 기능, 이미지·이벤트 데이터, 저장 시스템과 개발자 기능은 보존한다.

## 검증

브라우저 검증은 별도 QA 배포에서 3440×1440, 2520×1080, 1920×1080, 1920×900, 1600×1000 화면을 사용한다. 패널 경계, 글씨, 간판·줄, 5개 슬롯 및 클릭 영역, 썸네일, 착용·저장·불러오기, 책 카드·분류, 설정 탭·닫기를 확인한다. 검증용 이미지와 QA 페이지는 정식 브랜치에 포함하지 않는다.

## 거울·메인 메뉴 보완 (2026-10-11)

- 거울은 세로 공간 전체를 사용하고 오른쪽 꾸미기·저장 영역은 별도 grid로 배치한다. 목록만 스크롤하며 5개 저장 슬롯과 PNG 저장 기능은 유지한다.
- 메인 메뉴 글씨는 최대 34px에서 56px, 옷장 라벨은 26px에서 42px로 늘린다. 옷장 라벨만 가로 폭을 늘려 글씨와 아이콘이 들어가게 한다. 집·일기장 위치는 보존한다.
- 팻말의 반복 흔들림은 ±8도에서 ±5도, 집 클릭 후 첫 반동은 -18도에서 -12도로 완화한다. 다른 키프레임·속도는 유지한다.

## 글씨 크기와 거울 안쪽 여백 재조정

메인 메뉴는 56px에서 44px, 옷장 라벨은 42px에서 32px로 낮추었다. 옷장 라벨은 배경 이미지의 원래 위치와 폭으로 복원하여 배경 크롭과 글씨가 다시 일치하게 했다. 세로 거울 높이는 유지하고 폭을 줄였으며 오른쪽 안쪽 여백을 더 두어 왼쪽 미리보기 영역 안에 안정적으로 배치했다. 팻말과 다른 모션, 이미지 좌표와 저장 기능은 그대로 유지한다.

거울 폭은 후속 요청에 따라 다시 넓혔다. 높이와 중심 위치는 유지하며, 미리보기 영역의 왼쪽 8px·오른쪽 20px 여백을 확보한 범위에서 세로 높이의 72%까지 폭을 허용한다. 추가 확대 요청에 맞춰 거울 영역은 내부 가로 공간의 34%, 오른쪽 목록·저장 영역은 66%로 조정했다.

## 거울 바깥으로 이미지 확대

거울 미리보기의 자동 축소·자동 위치 보정을 제거했다. 화면 크기에 맞춘 기본 캔버스 배율은 유지하며 저장된 확대율·위치·회전은 그대로 표시한다. 이미지가 거울보다 커져도 유리나 옷장 패널에서 자르지 않으며 이미지 레이어는 클릭을 가로채지 않는다. 거울 디자인, 목록 스크롤, 저장 좌표와 PNG 내보내기 캔버스는 유지한다.
