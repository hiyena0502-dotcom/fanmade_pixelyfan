# 모션 자동 축소 제거

사용자 요청에 따라 사이트는 PC의 prefers-reduced-motion 설정으로 모션을 자동 축소하거나 느리게 만들지 않는다. 사이트 설정의 모션 켜기·끄기는 기존대로 유지하며 기존 저장 값도 보존한다.

- 메인 제목: 기존 title-rock의 ±2.4도 및 3.8초 주기를 사용한다.
- 문 팻말: 기존 sign-sway의 ±8도 및 2.8초 주기를 사용한다.
- 집 클릭: 원래의 눌림·도약·착지 키프레임과 780ms를 사용한다. 팻말 반동은 2200ms다.
- 덤불 클릭: 원래의 1350ms 흔들림과 8개 잎을 사용한다.
- 떠다니는 잎: 35% 속도 제한을 제거하고 흔들림·회전·뒤집힘을 모두 사용한다.
- 굴뚝 연기: 기존 7.2초 주기를 사용한다.
- 챕터 타이틀: 사이트 모션 설정에 따라 원형 전개·제목 확대·반짝임을 재생한다. 4.8초 시간표와 효과음은 유지한다.
- 책 넘김과 메뉴 전환에도 PC 동작 줄이기에 의한 별도 제한을 적용하지 않는다.

레이아웃, 이미지, 이벤트 및 저장 데이터는 변경하지 않는다. 브라우저 렌더링 지연 자체를 제거하는 변경은 아니다.
