# 안정화 검증 · 2026-10-10

기존 메인/옷장/책 디자인을 유지하고 플레이, 로컬 저장, 개발자 이미지와 이벤트 편집의 경계를 점검했다. 테스트 데이터는 별도 QA 브랜치와 QA 브라우저 저장소에서 사용했다. 일반 플레이어의 저장 슬롯과 서버 공개 콘텐츠를 초기화하지 않았다.

## 재현한 오류와 수정

| 문제 | 재현 근거 | 수정 |
| --- | --- | --- |
| 퍼즐을 닫으면 후속 보상 실행 | 수정 전 브라우저 검사 `FAIL cancel never grants reward` | 취소 시 해당 이벤트를 중단하고 퍼즐 완료/아이템 보상은 변경하지 않음 |
| 연속 퍼즐의 두 번째 단계 건너뜀 | 이전 창의 비동기 close 이벤트가 새 퍼즐에 적용되는 구조 | 취소 처리와 완료 처리를 분리하고 ESC도 같은 취소 경로 사용 |
| 자동 저장 중 도감 이동 시 복귀 기록 소실 | 실패한 회귀 테스트에서 복귀 snapshot이 undefined | 진행 중인 저장이 끝난 뒤 도감 복귀 snapshot 기록 |
| 클릭형 문·계단 이동 실패 | 조건을 만족한 이동 오브젝트에서 이동 false | 화면 양옆 화살표와 클릭형 오브젝트를 모두 이동 연결로 인식, 숨김/조건 유지 |
| 게임 이미지 저장 후 위치 변경 | X=90 편집값이 서버 정규화에서 50으로 변경 | 게임 이미지와 책 이미지의 조절 범위를 각각 유지 |
| 손상 슬롯 하나가 저장 목록 전체를 멈춤 | 읽기 단계에서 state.slot TypeError | 각 슬롯을 독립 확인, 손상 기록 보존·표시, 다른 슬롯은 정상 사용 |

추가로 새 게임 시작 중 중복 클릭과 중복 확인창을 막았고, 잘못된 이벤트/장소/캐릭터/아이템/퍼즐 연결은 반영 전에 검사하도록 했다. 개발자 편집 창을 열 때 서버 임시 저장본을 테스트에 적용하고, 플레이를 시작하지 않은 상태에서도 장면·이벤트 테스트를 시작할 수 있도록 고쳤다. 공개 콘텐츠를 읽지 못하면 새 게임을 저장하지 않고 연결 오류를 표시한다.

## 검증 범위

- 자동 테스트 43개 통과. 기존 옷장/설정/효과음/책 테스트와 신규 저장·이벤트·이미지 회귀 검사 포함.
- 수정 후 브라우저 안정화 검사 14개 통과: 취소, 오답, 연속 퍼즐, 보상 1회, 읽지 않은 대사 스킵 방지, 메뉴 출력 일시 정지·복귀, 중복 오브젝트 클릭 방지, 선택지 복귀, 16:9, 개발자 테스트 기록 분리.
- 프롤로그 전체 브라우저 검사 24개 통과: 조사→반복 조사→노크→선택지→장소 이동→아이템 사용·소모→퍼즐→자동 저장→이어하기.
- 책 편집 브라우저 검사 11개와 게임 편집 브라우저 검사 10개 통과: 업로드, 이미지 크기·위치·회전, 되돌리기, 임시 저장, 미리보기, 반영, 테스트 상태 분리. 편집 UI 검사는 격리된 테스트 응답을 사용했고 실제 서버 동작은 아래 검사로 별도 확인.
- 실제 서버 검사 7개 통과: 비공개 이미지 저장, 임시 저장/공개 분리, 충돌 방지, 공개 revision, 플레이 진행 미공유, 인증 세션, 익명 변경 차단.
- 도감 이동과 모험으로 돌아가기, 클리어 퍼즐 재조사를 직접 확인.
- JavaScript 구문 검사, 빌드, git diff 공백 검사 통과.

브라우저 확장 프로그램 자체의 metadata 메시지 오류는 프로젝트 소스 오류와 구분했다. 확인하지 않은 모든 환경에서 오류가 전혀 없다고 보장하는 결과는 아니다. 여러 실제 사용자 기기/브라우저와 장시간 전체 스토리 플레이는 아직 별도 검증 대상이다. 게임 진행은 계속 현재 기기·브라우저의 로컬 저장이다.
