# 꿈뜰이의 우당탕 생일 준비 대작전!!

잠뜰님의 생일 당일 아침, 꿈뜰이가 픽셀리 집에 도착하는 비공식 팬메이드 포인트앤클릭 게임입니다. 현재 재설계 버전은 `rebuild-v2` 브랜치에서 개발합니다.

## 실행과 검증

별도 빌드가 없는 정적 사이트입니다. `python -m http.server 8080`으로 실행할 수 있습니다. 현재 게임 진행 검증은 `node --test tests/rebuild.test.js`로 실행합니다.

## 현재 구현

- `index.html`, `rebuild.js`, `styles/rebuild.css`: 새 메인 화면과 게임 화면.
- 집 앞은 비율을 다시 맞춘 사용자 첨부 12장(v163)의 2048×1152 좌표를 그대로 유지한 무손실 WebP로 겹칩니다. 16:9 화면을 채우며, 앞 덤불에는 별도 확대 보정을 적용하지 않습니다. 구름 1~6은 집 뒤에서 오른쪽에서 왼쪽으로 천천히 흘러가며 간격을 유지합니다. 눈이 내리고 땅에 닿으면 사라지며, 문 간판·새집 캐릭터·파란색 지렁이는 새 좌표에서 움직이며, 수건은 정지된 이미지로 표시합니다. 모든 레이어와 현관문 클릭 영역은 함께 확대·축소됩니다.
- 집 앞에서 문을 누르면 문 앞 화면으로 이동합니다. 첫 방문에는 문 앞에서 노크와 입장 대화가 나옵니다. 초대를 받은 뒤에는 문 앞의 문을 누르면 대사 없이 입장 선택지만 표시하며, 기존 저장의 반복 입장 대화도 선택지로 복구합니다.
- ‘조금 더 둘러본다’는 문 앞에 남습니다. 집 앞으로 돌아가기는 별도 버튼입니다.
- 배경은 화면을 채우며, 거실 캐릭터는 배경과 같은 좌표계에서 테이블 왼쪽에 배치됩니다. 캐릭터 이미지의 투명 여백은 자동으로 측정합니다.
- 첫 입장 시 Chapter I 이후 사용자 원문인 공룡·꿈뜰이·라더·덕개 도입 대화 18줄과 선택지 3개를 진행합니다. 공룡은 초록 자막바, 라더는 빨강 자막바를 사용하며 덕개만 주방 쪽 난입 말풍선으로 표시합니다. 선택지 응답 종료 후 장식 부탁이 기록장에 남으며, 대사/분기 중 새로고침해도 이어집니다.
- 테이블 옆 배치용 공룡과 대화용 큰 공룡 이미지를 별도 요소로 표시합니다. 대화용 이미지는 `member-dialogue.js`의 `members.gongryong.portrait`만 교체할 수 있습니다. 라더·덕개·각별·수현은 사용자 첨부 순서대로 대화용 이미지를 등록했습니다. 라더의 기존 대사에는 해당 이미지를 표시합니다. 네 명은 방에 새로 배치하지 않으며, 덕개의 기존 난입 말풍선은 유지합니다.
- 챕터 연출 중에도 배치 캐릭터와 HUD가 표시됩니다. 연출 및 대화 동안 입력은 잠깁니다.
- 대화를 마친 뒤 공룡을 클릭하면 “왜, 벌써 찾았어?”로 시작하는 세 대사 이후 선택지가 나옵니다. 이름은 자막바 위의 얇은 색 테두리 이름표로 표시하고, 대사는 바 전체 폭의 중앙에 정렬합니다. 이름 옆 아이콘은 제거했습니다. 라더 대화용 이미지와 이름표는 오른쪽에, 꿈뜰이의 이름표도 오른쪽 위에 표시합니다. 대사창은 높이를 줄여 하단으로 내리며 대화용 캐릭터의 하단을 가립니다. 완료한 선택지는 저장해 어둡게 표시하며 다시 선택할 수 있습니다. 챕터 장식과 제목은 화면 중앙에 표시됩니다. `member-dialogue.js`와 `styles/member-dialogue.css`가 실제 게임/시안의 공통 UI입니다. “어떤 장식인데요?”에는 또니·티티에 관한 공룡과 라더의 여섯 대사가 이어집니다.
- `dialogue-preview.html`에서 게임 저장에 영향을 주지 않고 대화/선택지를 볼 수 있습니다.
- 대화 중에는 이동 화살표와 아이템/도구 UI를 숨기지만, 방에 배치한 캐릭터는 유지합니다. 대사와 선택지는 중앙 정렬과 따뜻한 얇은 테두리 UI를 사용하고, 읽은 선택지도 다시 선택할 수 있습니다. 덕개 난입 말풍선은 표시만 하며, 하단 대화창에서 진행합니다.
- 할 일과 퀘스트는 기록장에서만 확인하며, 새로 받으면 중앙 알림이 한 번 표시된 뒤 사라집니다. 힌트는 오른쪽 위 작은 아이콘을 누르면 창이 열립니다. 힌트 문구는 아직 정하지 않아 내용은 비어 있으며, 총 수집 개수나 요정 위치도 미리 표시하지 않습니다.
- 기록장에는 할 일만 표시하며 새 부탁을 확인하면 알림 표시를 지웁니다.
- 거실 왼쪽은 주방, 오른쪽은 계단입니다. 화장실은 계단 화면 오른쪽, 창고는 주방 뒤쪽에 연결하되 진입 화살표는 주방 화면 왼쪽 중앙에 둡니다. 계단·화장실·창고는 배경 이미지가 준비되기 전의 SVG 도형으로 표현하며 돌아오기와 위치 저장을 지원합니다. 이동 화살표에는 글자를 표시하지 않으며 왼쪽 중앙·오른쪽 중앙·아래 중앙만 사용합니다.
- 계단은 왼쪽으로 올라가는 방향이며 계단 그림 위의 “2층으로 가기”를 클릭해 이동합니다. 2층은 계단을 올라와 긴 복도 끝 요정방을 바라보는 원근 구도로 표현합니다. 입구에서 안쪽으로 왼쪽 수현→각별→잠뜰, 오른쪽 라더→덕개→공룡 순서로 방문이 보이며, 아래 중앙 화살표로 계단에 돌아옵니다. 방 문은 현재 배경 도형이며 요정방에는 들어갈 수 없습니다.
- 지하는 2층 계단 옆의 “지하로 가기”를 눌러 이동하는 촬영 소품 보관실입니다. 다락은 2층 복도의 천장 입구와 사다리에서 “다락으로 가기”를 눌러 이동하며 낮은 지붕 아래 보관 공간으로 표현합니다. 두 공간 모두 도구, 위치 저장, 이어하기와 아래 중앙 복귀 화살표를 지원합니다.
- 집 앞, 문 앞과 모든 실내 공간에서 가방·기록장·메뉴·빈 힌트 창을 열 수 있습니다. 시작한 챕터의 연출은 현재 위치를 유지한 채 다시 볼 수 있습니다. 장식 수집을 위한 요정 이벤트와 후속 챕터는 아직 구현되지 않았습니다.
- 게임 위치와 도입 진행은 `pixely-rebuild-save-v1`에 저장합니다. 문 앞에서도 이어할 수 있으며, 브라우저 저장이 차단된 경우 현재 탭의 진행은 유지합니다.
- `wardrobe.html`은 기존 꿈뜰이 옷장과 저장 구조를 유지합니다. 옷장 선택 카드의 크기를 줄여 한 줄에 네 개씩 표시하며 원본 이미지는 카드 안에 전체가 보이도록 맞춥니다. `app.js`, `data/`, 기존 기능별 CSS는 옷장 호환을 위해 남겨 두었습니다.

`site-version.json`의 `version`은 기존 옷장 스크립트 버전, `rebuildVersion`은 새 게임 버전입니다. 새 게임의 CSS/JS 캐시 버전은 `index.html`에서 함께 변경합니다.

기존 `tests/app.test.js`에는 폐기된 게임 화면과 현재 `index.html`이 예전 구조라고 가정하는 검사가 포함되어 있습니다. 해당 검사의 기존 실패를 새 게임 검증과 혼동하지 않도록 구분합니다.
