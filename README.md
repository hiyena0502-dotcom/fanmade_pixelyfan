# PIXELY : LOST SKY

잠뜰님의 생일을 준비하다 여러 이야기의 세계를 여행하게 되는 비공식 팬메이드 코미디 어드벤처입니다. 현재는 챕터 1 도입 장면과 파티방 조사 화면, 미션·인벤토리, 컬렉션, 꿈뜰이 옷장, 저장 관리가 구현되어 있습니다.

## 실행

정적 사이트입니다. `index.html`을 열거나 로컬 정적 서버에서 실행할 수 있습니다. 별도 빌드와 외부 패키지는 필요하지 않습니다.

## 현재 구조

- **HOME** — 새 이야기, 이어하기, 세이브 슬롯 관리
- **CHAPTER 1** — 새 이야기에서 집 전경의 문을 클릭하면 문 클로즈업으로 바뀝니다. 이어서 실내 파티방 위에 챕터 제목이 나타나며 조사 화면으로 이어집니다.
- **CHAPTERS** — 챕터 진행 기록
- **COLLECTION** — 인물 카드, 아이템, 엽서 다이어리
- **WARDROBE** — 홈 오른쪽 위의 별도 버튼으로 여는 밝은 꾸미기 화면. 브라우저에서 직접 베이스/옷/소품/얼굴/장식 이미지를 추가할 수 있고, 네 분류 모두 여러 레이어를 동시에 선택할 수 있습니다. 각 이미지의 좌우·위아래·크기·회전과 레이어 순서도 조정할 수 있습니다.

기존 세이브는 그대로 읽습니다. 이미 인트로를 마친 세이브는 이어하기에서 도입 장면을 다시 재생하지 않습니다.

## 파일

- `index.html` — 화면 구조
- `style.css` — 기능별 CSS를 불러오는 진입점
- `styles/` — `core`, `home`, `chapters`, `collection`, `story`, `wardrobe`, `editor` 화면별 스타일
- `data/game-config.js` — 카드·아이템·챕터·옷장 분류·스토리 기본 데이터
- `data/editor-schema.js` — 컬렉션 카드·엽서 편집 필드 스키마
- `app.js` — 저장, 화면 렌더링, 챕터 진행, 컬렉션, 옷장, DEV EDITOR 동작
- `site-version.json` — 배포된 사이트 버전

세이브는 브라우저 `localStorage`의 `pixely-lost-sky-saves-v2` 키에 슬롯 세 개로 저장됩니다. 브라우저 데이터를 지우면 세이브도 삭제됩니다.

컬렉션의 카드 목록은 잠뜰 멤버·상황극 인물·요정·기타로 분류됩니다. 앞으로 카드 항목에 `world` 문자열을 추가하면 해당 작품 필터도 자동으로 나타납니다. 아직 작품별 캐릭터 데이터는 입력하지 않았습니다. 아이템은 중요 물건·기념품·선물·꾸미기·미확인으로 나뉩니다. 엽서는 기존 한 목록을 유지합니다.

새 게임의 인벤토리는 비어 있습니다. 기존 봉제인형을 획득하면 옷장에서 소품으로 장착할 수 있습니다. 추후 `catalogue.items`에 `wardrobeSlot`(`outfit`, `accessory`, `face`, `decoration`)이 지정된 아이템을 추가하고 스토리에서 `window.PixelyInventory.grantItem(itemId)`로 지급하면 선택 항목이 늘어납니다. 옷·소품·얼굴·장식은 모두 `outfit.layers`의 복수 레이어로 저장됩니다. 예전 단일 `outfit/accessory/face/headwear` 세이브는 불러올 때 새 레이어 배열로 변환해 호환합니다. 이미지 소재가 들어온 뒤 대화 화면은 `window.PixelyAvatar.outfitForActiveSave()`에서 장착 상태를 읽어 사용자 이미지에 적용할 수 있습니다.

## 배포할 때

사이트 파일을 수정하면 `app.js`의 `SITE_VERSION`, `site-version.json`의 `version`, `index.html`의 CSS/JS `?v=` 값을 같은 새 값으로 올려 주세요. 열린 탭은 배포 버전이 달라지면 새로고침 안내를 표시합니다. `node --test tests/*.test.js`로 주요 동작과 버전 일치를 확인할 수 있습니다.

### 옷장 이미지 편집

옷장 하단의 **이미지 추가 · 위치 조정**에서 투명 PNG/WEBP/JPG를 직접 등록할 수 있습니다. 베이스 이미지는 별도 업로드하며, 현재 열어 둔 옷 / 소품 / 얼굴 / 장식 탭에 새 파츠 이미지를 추가합니다. 등록한 이미지는 브라우저 IndexedDB의 `pixely-dev-data-v1` 저장소에 보관되고, 좌우(X)·위아래(Y)·크기·회전 값을 이미지별로 기억합니다. 장식 이미지는 여러 개를 동시에 선택해 겹칠 수 있습니다. 이미지는 등록 시 크기를 검사하고 가능한 경우 최적화합니다.


> 옷장 이미지 업로드/위치 조정 UI는 개발자 세팅용 임시 도구입니다. 최종 베이스·파츠 이미지와 위치가 확정되면 해당 설정을 기본 에셋/기본 transform으로 코드에 고정하고, 업로드·위치 조정 UI는 제거할 예정입니다.


### 옷장 레이어 구조 v22

옷·소품·얼굴·장식은 모두 복수 선택 가능한 레이어입니다. 얼굴은 눈/입/눈썹/볼, 의상은 상의/하의/겉옷/신발처럼 세부 파츠를 나눠 등록할 수 있습니다. 소품은 캐릭터가 들거나 착용하는 물건, 장식은 캐릭터 주변의 이펙트·스티커·꾸밈 요소로 구분합니다. 옷장 화면에서 적용된 파츠의 좌우·위아래·크기·회전뿐 아니라 레이어 순서(맨 아래/한 칸 아래/한 칸 위/맨 위)도 조정할 수 있습니다.


### 컬렉션 편집기

홈의 **컬렉션 편집 / COLLECTION EDITOR** 버튼에서 카드와 엽서만 수정합니다.

- **카드**: 이름, 분류, 심볼, 색상, 상황극·세계, 설명, 꿈뜰이 메모
- **아이템**: 현재 등록된 아이템의 이름, 분류, 설명, 옷장 연결 정보
- **엽서**: 이름, 분류, 심볼, 색상, 설명, 캡션
- 편집 내용은 초안에서 UNDO/REDO할 수 있고 **저장**을 눌러 적용합니다.
- 챕터·상호작용·옷장 설정은 이 에디터에 포함하지 않습니다.

컬렉션 편집 데이터는 플레이 세이브와 분리된 IndexedDB에 저장되며, IndexedDB를 쓸 수 없는 환경에서는 기존 localStorage 저장을 사용합니다.

### 코드 정리 · v45

정적 콘텐츠와 에디터 스키마를 거대한 `app.js`에서 분리했습니다. `data/game-config.js`는 게임 기본 데이터만, `data/editor-schema.js`는 개발자 편집기의 입력 구조만 담당하고 `app.js`는 상태·저장·렌더링·이벤트 처리에 집중합니다. 기존 세이브/IndexedDB 키와 화면 동작은 바꾸지 않습니다.


### CSS 구조 정리 · v46

기존 4천 줄 이상의 단일 `style.css`에 누적되던 버전별 PATCH 블록을 화면 기능별 CSS로 분리했습니다. `style.css`는 import 진입점만 담당하고 실제 스타일은 `styles/core.css`, `home.css`, `chapters.css`, `collection.css`, `story.css`, `wardrobe.css`, `editor.css`에서 관리합니다. 이후 특정 화면을 수정할 때 해당 파일만 보면 되며, 새 버전 패치를 파일 맨 아래에 계속 덧붙이지 않는 구조를 기준으로 합니다.


### 컬렉션 전용 에디터 · v47

DEV EDITOR에서 챕터·상호작용·아이템·옷장·데이터 관리 기능을 제거했습니다. 에디터는 **컬렉션 카드와 엽서**만 추가·수정·삭제하며, 변경 내용은 초안에서 UNDO/REDO 후 저장할 수 있습니다. 실제 게임의 챕터 진행, 하드코딩 상호작용, 플레이어 옷장은 그대로 유지됩니다.


### v48 수정

컬렉션 편집기에 기존 아이템 편집 탭을 복구했습니다. 기본 카드·아이템·엽서 데이터는 새로 추가하지 않았습니다. CSS 모듈 분리 뒤 깨진 챕터 1 집 전경/문 클로즈업 이미지 경로를 수정했고, 집 안에서 여행 다이어리를 열었을 때 뒤로가기가 HOME이 아니라 원래 스토리 화면으로 돌아가도록 변경했습니다.


### 컬렉션 초기화 · v49

기본 컬렉션 데이터를 비워 **카드 0 / 아이템 0 / 엽서 0**으로 시작합니다. 이전 v1 컬렉션 개발 데이터는 v49 최초 로드에서 빈 컬렉션으로 한 번 초기화되며, 플레이 세이브와 옷장 이미지 데이터는 유지합니다. 이후 컬렉션 편집기에서 직접 추가한 항목만 저장됩니다. 여행 다이어리 버튼의 이전 화면 감지 오류도 함께 수정했습니다.


### 집 앞 애니메이션·문 앞 조사 · v51

챕터 1 집 전경에 바람에 흩날리는 나뭇잎 레이어를 추가했습니다. 문을 클릭해 가까이 간 뒤 멤버들의 대사를 들으면 바로 실내로 넘어가지 않고 **집 안으로 들어갈까? / 주변을 더 둘러볼까?** 선택지가 나타납니다. 둘러보기를 고르면 문 주변 조사 포인트와 집 전경으로 돌아가는 화살표가 표시되며, 다시 문으로 접근할 때 이미 들은 대사는 반복하지 않습니다.


### 집 앞 HUD·뒤로가기 개선 · v52

집 전경이 보이는 시점부터 하단 게임 HUD를 표시합니다. 가방과 빠른 아이템 칸, 현재 목표, 지도, 여행일지, 저장을 집 밖에서도 사용할 수 있습니다. 문 앞 화면에서는 대사·선택지·조사 중 모두 눈에 띄는 **← 집 앞** 버튼을 표시하며, 누르면 문 클로즈업이 아니라 집 전체 전경으로 돌아갑니다.


### 집 앞 조사·외부 지도 개선 · v53

집 전경의 문 인터랙션을 다른 조사 포인트와 같은 **돋보기 아이콘**으로 통일했습니다. 문 앞 대사가 끝나면 별도 선택지 창을 띄우지 않고 조사 모드로 이어지며, 문 돋보기를 직접 눌렀을 때만 **집 안으로 들어가기** 버튼이 나타납니다. 조사 문장은 화면 아래에 잠시 나타난 뒤 자동으로 사라집니다. 집 밖에서 지도를 열면 파티방 실내 지도 대신 **집 앞 / 현관 / 집 안 / 주변 길** 기준의 외부 지도가 표시됩니다.


### 집 밖 홈 바로가기 · v54

집 전경이 나타난 뒤부터 현관 앞 대사·조사 구간까지 오른쪽 위에 **⌂ 홈** 버튼을 표시합니다. 집 안으로 들어가기 전에도 언제든 메인 화면으로 돌아갈 수 있습니다.
