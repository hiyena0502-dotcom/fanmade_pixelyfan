# 꿈뜰이의 우당탕 생일 준비 대작전!!

잠뜰님의 생일 당일 아침, 꿈뜰이가 픽셀리 집에 도착하는 비공식 팬메이드 포인트앤클릭 게임입니다. 현재 재설계 버전은 `rebuild-v2` 브랜치에서 개발합니다.

## 실행과 검증

별도 빌드가 없는 정적 사이트입니다. `python -m http.server 8080`으로 실행할 수 있습니다. 현재 게임 진행 검증은 `node --test tests/rebuild.test.js`로 실행합니다.

## 현재 구현

- `index.html`, `rebuild.js`, `styles/rebuild.css`: 새 메인 화면과 게임 화면.
- 집 앞은 첨부 원본의 2048×1339 좌표를 유지한 무손실 WebP 7개를 하늘 → 나무·산 → 울타리 → 집 → 땅 → 덤불 → 오브젝트 순서로 겹칩니다. 구름 1~6은 울타리와 집 사이에서 접속마다 다른 속도·시작 간격으로 화면 왼쪽에서 오른쪽으로 계속 흘러가며, 흐릿한 앞 덤불은 오브젝트보다 앞에서 9% 위로 올려 표시됩니다. 모든 레이어와 현관문 클릭 영역은 함께 확대·축소됩니다.
- 집 전체 배경에서 문을 클릭하면 문 앞 배경으로 전환합니다. 문을 다시 클릭해야 입장 선택지가 나타납니다.
- ‘조금 더 둘러본다’는 문 앞에 남습니다. 집 앞으로 돌아가기는 별도 버튼입니다.
- 배경은 화면을 채우며, 거실 캐릭터는 배경과 같은 좌표계에서 테이블 왼쪽에 배치됩니다. 캐릭터 이미지의 투명 여백은 자동으로 측정합니다.
- 첫 입장 시 Chapter I 이후 사용자 원문인 공룡·꿈뜰이·라더·덕개 도입 대화 18줄과 선택지 3개를 진행합니다. 공룡은 초록 자막바, 라더는 빨강 자막바를 사용하며 덕개만 주방 쪽 난입 말풍선으로 표시합니다. 선택지 응답 종료 후 장식 부탁이 기록장에 남으며, 대사/분기 중 새로고침해도 이어집니다.
- 테이블 옆 배치용 공룡과 대화용 큰 공룡 이미지를 별도 요소로 표시합니다. 대화용 이미지는 `member-dialogue.js`의 `members.gongryong.portrait`만 교체할 수 있습니다. 라더 대화용 이미지는 아직 제공되지 않아 숨겨지며 별도로 연결할 수 있습니다.
- 챕터 연출 중에도 배치 캐릭터와 HUD가 표시됩니다. 연출 및 대화 동안 입력은 잠깁니다.
- 대화를 마친 뒤 공룡을 클릭하면 “왜, 벌써 찾았어?”로 시작하는 세 대사 이후 선택지가 나옵니다. 꿈뜰이의 이름과 별 아이콘은 자막바 오른쪽에 표시됩니다. 공룡·라더 아이콘은 사용자 첨부 이미지를 사용합니다. 대사창은 높이를 줄여 하단으로 내리며 대화용 캐릭터의 하단을 가립니다. 완료한 선택지는 저장해 어둡게 표시하며 다시 선택할 수 있습니다. 챕터 장식과 제목은 화면 중앙에 표시됩니다. `member-dialogue.js`와 `styles/member-dialogue.css`가 실제 게임/시안의 공통 UI입니다. “어떤 장식인데요?”에는 또니·티티에 관한 공룡과 라더의 여섯 대사가 이어집니다.
- `dialogue-preview.html`에서 게임 저장에 영향을 주지 않고 대화/선택지를 볼 수 있습니다.
- 대화 중에는 이동 화살표와 아이템/도구 UI를 숨기지만, 방에 배치한 캐릭터는 유지합니다. 대사와 선택지는 따뜻한 얇은 테두리 UI를 사용하고, 읽은 선택지도 다시 선택할 수 있습니다. 덕개 난입 중에는 난입 말풍선에서 진행합니다.
- 미션은 ‘생일 장식 찾기’로 간단히 표시합니다. 선택형 힌트는 공룡에게 실제로 들은 내용만 한 개씩 공개하며, 총 수집 개수나 요정 위치를 미리 표시하지 않습니다. `journal.js`가 들은 정보와 힌트 공개 범위를 관리합니다.
- 기록장은 할 일/메모로 나누며 새 메모 표시를 확인한 뒤 지웁니다. 지난 대화는 선택과 난입을 포함해 최근 200줄을 저장합니다. 대화 이력을 열면 노크 등의 시간 연출도 잠시 멈추고, 닫으면 이어집니다.
- 거실과 주방에서 가방과 기록장을 열 수 있습니다. 장식 수집을 위한 다른 방·요정 이벤트와 후속 챕터는 아직 구현되지 않았습니다.
- 게임 위치와 도입 진행은 `pixely-rebuild-save-v1`에 저장합니다. 문 앞에서도 이어할 수 있으며, 브라우저 저장이 차단된 경우 현재 탭의 진행은 유지합니다.
- `wardrobe.html`은 기존 꿈뜰이 옷장과 저장 구조를 유지합니다. `app.js`, `data/`, 기존 기능별 CSS는 옷장 호환을 위해 남겨 두었습니다.

`site-version.json`의 `version`은 기존 옷장 스크립트 버전, `rebuildVersion`은 새 게임 버전입니다. 새 게임의 CSS/JS 캐시 버전은 `index.html`에서 함께 변경합니다.

기존 `tests/app.test.js`에는 폐기된 게임 화면과 현재 `index.html`이 예전 구조라고 가정하는 검사가 포함되어 있습니다. 해당 검사의 기존 실패를 새 게임 검증과 혼동하지 않도록 구분합니다.
