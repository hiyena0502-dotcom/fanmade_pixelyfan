# 꿈뜰이의 우당탕 생일 준비 대작전!!

잠뜰님의 생일 당일 아침, 꿈뜰이가 픽셀리 집에 도착하는 비공식 팬메이드 포인트앤클릭 게임입니다. 현재 재설계 버전은 `rebuild-v2` 브랜치에서 개발합니다.

## 실행과 검증

별도 빌드가 없는 정적 사이트입니다. `python -m http.server 8080`으로 실행할 수 있습니다. 현재 게임 진행 검증은 `node --test tests/rebuild.test.js`로 실행합니다.

## 현재 구현

- `index.html`, `rebuild.js`, `styles/rebuild.css`: 새 메인 화면과 게임 화면.
- 집 전체 배경에서 사물을 조사한 뒤 문을 클릭하면 문 앞 배경으로 전환합니다. 문을 다시 클릭해야 입장 선택지가 나타납니다.
- ‘조금 더 둘러본다’는 문 앞에 남습니다. 집 앞으로 돌아가기는 별도 버튼입니다.
- 집 전체와 문 앞 배경은 사용자 제공 원본 PNG를 사용하며, 비율과 전체 구도를 유지합니다. 사물 클릭 영역은 이미지와 같은 좌표계에 배치합니다.
- 첫 입장 시 Chapter I과 공룡·라더·덕개의 도입 대화가 나옵니다. 대화가 끝나면 장식 부탁이 기록장에 남습니다. 이후 재입장에서는 자동 대화를 반복하지 않습니다.
- 거실에서 가방과 기록장을 열 수 있습니다. 장식 수집을 위한 다른 방·요정 이벤트와 후속 챕터는 아직 구현되지 않았습니다.
- 게임 위치와 도입 진행은 `pixely-rebuild-save-v1`에 저장합니다. 문 앞에서도 이어할 수 있으며, 브라우저 저장이 차단된 경우 현재 탭의 진행은 유지합니다.
- `wardrobe.html`은 기존 꿈뜰이 옷장과 저장 구조를 유지합니다. `app.js`, `data/`, 기존 기능별 CSS는 옷장 호환을 위해 남겨 두었습니다.

`site-version.json`의 `version`은 기존 옷장 스크립트 버전, `rebuildVersion`은 새 게임 버전입니다. 새 게임의 CSS/JS 캐시 버전은 `index.html`에서 함께 변경합니다.

기존 `tests/app.test.js`에는 폐기된 게임 화면과 현재 `index.html`이 예전 구조라고 가정하는 검사가 포함되어 있습니다. 해당 검사의 기존 실패를 새 게임 검증과 혼동하지 않도록 구분합니다.
